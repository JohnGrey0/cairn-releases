# Cairn releases

Cairn is a private, all-in-one AI assistant that runs entirely on your own Windows PC. It reads your documents and
email, builds a knowledge graph of the people, places, accounts and events in them, and organizes everything into an
Obsidian vault. All AI processing happens locally; nothing is sent to a cloud AI provider.

This repository only hosts **installers and update manifests**. The source code is private.

## Download
Grab the latest `Cairn_x.y.z_x64-setup.exe` from [Releases](../../releases/latest). The installer needs no admin rights.
On first launch Cairn downloads its local AI components (several GB) and walks you through setup.

## Requirements
- Windows 10/11 (64-bit)
- 16 GB RAM minimum (32 GB+ recommended)
- An NVIDIA GPU with 8 GB+ VRAM is recommended; CPU-only works, but slowly

## Updates
Installed copies check this repository's `latest.json` for signed updates.
